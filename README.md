# Siddharth Raina

I check whether the numbers LLM and agent evaluations report mean what they are taken to mean.
Data scientist with over a decade of experience, based in Berlin.

**What I look for**

Eval defects rarely crash. They produce plausible numbers: a metric that reports zero when nothing
was measured, a success rate that counts attempts the grader rejected, a score computed over a
different set of samples than the one it claims. I look for these by re-deriving what each number
was computed over, and by reading the cases a check didn't match before trusting its count.

How I approach it: [how I evaluate evaluations](https://raina-sid.github.io/method.html).
